# kola_flutter

Scaffold for a future native Kola mobile app. **Not on the Phase 1–7 critical path** — the MVP1 dashboard is a Jaspr (client-mode) web app, not Flutter; see `docs/SRS.md` §3. This package stays as the unmodified Serverpod Flutter template until a native mobile app is actually scheduled.

## Getting Started

This project is a starting point for a Flutter application that is using
Serverpod.

A great starting point for learning Serverpod is our documentation site at:
[https://docs.serverpod.dev](https://docs.serverpod.dev).

To run the project, first make sure that the server is running, then do:

    flutter run
